# Mini tienda

Proyecto de una tienda pequeña dividido en dos partes independientes:

| Carpeta                 | Qué contiene                                            | Tecnología                                 |
|-------------------------|---------------------------------------------------------|--------------------------------------------|
| [python/](python/)      | API, base de datos, migraciones, scripts y pruebas      | FastAPI, SQLAlchemy, PostgreSQL (Supabase) |
| [frontend/](frontend/)  | Interfaz de usuario (en construcción)                   | TypeScript y Node.js                       |

Cada carpeta tiene sus propias dependencias y se ejecuta por separado.
Las instrucciones del backend están en [python/README.md](python/README.md).
